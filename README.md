
# AcessoryHub

Projeto em MySQL que modela um sistema de gestão para lojas físicas de acessórios, com controle de vendas, produtos, funcionários e pedidos. O projeto é desenvolvido 100% em código SQL nativo, com complemento de análise e visualização de dados no Power BI, reforçando conceitos de modelagem de banco de dados e organização de dados para análise.


## ❌ Problema

Pequenas lojas físicas de acessórios enfrentam dificuldades na gestão de suas vendas devido à dependência de processos manuais, geralmente realizados em planilhas ou registros informais. Esse cenário acaba gerando:

- Erros manuais no controle das vendas

- Produtos não registrados ou cadastrados de forma incorreta

- Baixa organização na administração de produtos e pedidos

- Dificuldades no acompanhamento de devoluções e correções de vendas

- Impossibilidade de consultar rapidamente a disponibilidade de acessórios

- Falta de controle sobre o desempenho de vendas por funcionário

- Essas limitações comprometem a eficiência operacional e dificultam a tomada de decisões.

## ✅ Melhorias

Com esse novo sistema, as lojas passam a contar com:

- Controle detalhado de cada venda realizada

- Gestão organizada de produtos e estoque

- Acompanhamento estruturado dos pedidos e seus respectivos status

- Monitoramento do desempenho de vendas por funcionário

- Base de dados consistente para análises e relatórios gerenciais

- Tudo isso com mais transparência, eficiência e menor dependência de processos manuais.
